# Living Plan

A small planner you can install on a phone's Home Screen. Each area of life is a cell; a cell grows as you add tasks, notes, dates and links to it, and fills as you finish things.

- Everything you enter is stored on your own device. Nothing is sent anywhere.
- Works offline once opened.
- Use **Backup → Copy all data** to keep a copy, and **Paste data in** to restore it.

## Install on iPhone
1. Open the app's address in Safari.
2. Tap Share, then **Add to Home Screen**.
3. Open it from the new icon.

## Build
`python build.py` regenerates `index.html` and the icons from `../living-plan.html`.
